# Website demo mới nhất của WareMap

Link chia sẻ: https://DucHM2410.github.io/WAREMAP/

Workflow `.github/workflows/deploy-pages.yml` tự build, kiểm tra TypeScript và xuất bản mỗi khi nhánh `main` có commit mới. Chờ workflow **Publish WareMap demo** báo thành công trước khi kiểm tra bản mới.

Vào trang **Đăng nhập**, chọn một thẻ vai trò để thử ngay, hoặc dùng các tài khoản trong `DEMO_GUIDE.md`. Mật khẩu demo chung: `WareMap@123`.

Đây là bản frontend demo công khai. Dữ liệu mẫu lưu riêng trên trình duyệt của từng người, chưa đồng bộ giữa các thành viên. Không cần bật máy phát triển để truy cập.

Link Sites cũ trong `CHIA_SE_WEB.md` là một bản triển khai độc lập, không tự cập nhật theo GitHub Pages.
