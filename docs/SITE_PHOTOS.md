`waremap-3d-screen.png` is an actual browser screenshot of WareMap's read-only
sample warehouse, captured 2026-10-30. It contains sample inventory only.
The About page uses four distinct images: the product screen, barcode/tablet
inventory work, handheld stock checks, and computer-assisted packing.

Files in `src/assets/site-photos/` are bundled by Vite, including under the
GitHub Pages `/WAREMAP/` base. `sitePhotos.ts` maps them to public pages and
sections with empty CMS image fields. Custom images keep priority. CMS draft
and export formats are unchanged; hashed build URLs are never persisted.
